
# Student Management System

A beginner-friendly student record management program built with Python.

## Features
- Add student records
- View all students
- Search students by roll number
- Delete student records
- Store records permanently in a JSON file
- Validate marks and prevent duplicate roll numbers

## Technologies Used
- Python 3
- JSON
- File Handling
- Functions and Loops

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   python student_management.py

## Data Storage
Student records are saved in `students.json`.
This file is created automatically when a student is added.
